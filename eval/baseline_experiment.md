# Single-task baseline experiment

The baseline measures how well each model solves a task in isolation. Every
episode has a one-node graph: the model requests that node's input, solves it
with the same agent tools used in larger graphs, and submits the target answer.
The generated datasets are shared across models.

| Category | Native tasks | Samples per task | Episodes per model |
|---|---:|---:|---:|
| Math | 40 | 8 | 320 |
| Python | 80 | 8 | 640 |
| RLVE | 40 | 8 | 320 |
| RAG | 200 distinct HotpotQA questions | 1 | 200 |

That is 1,480 episodes per model. The datasets use seed 0 and are generated by
[`generate/gen_exp1_datasets.sh`](generate/gen_exp1_datasets.sh). Qwen3.8-27B
and Nemotron-3-Nano-Omni-30B-A3B use the local runner
[`run_exp1.sh`](eval/slurm_scripts/run_exp1.sh); GPT-OSS-120B uses
[`run_exp1_api.sh`](eval/slurm_scripts/run_exp1_api.sh). Qwen3.6-35B-A3B is the
planned fourth model.

[`grade_results.py`](eval/grade_results.py) scores target correctness: exact
integers and tolerance-based floats for math, Python, and RLVE, and official
HotpotQA joint exact match for RAG. Report accuracy by model and category.
These rates establish task difficulty and help screen pools for the gap
experiment; its predictions use separate pinned calibration repeats.
