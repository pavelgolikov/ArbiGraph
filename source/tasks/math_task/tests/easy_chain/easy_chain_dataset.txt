Task 1:
To get task_1_input, call the get_input tool with task_index=1 and input_dependencies=[].
Let task_1_input = [a_0, a_1, ..., a_{N-1}]. Let p be the smallest prime number of the form m*N + 1 for a positive integer m.
All arithmetic in this transform is modulo p. Let g be the smallest positive primitive root modulo p, and define omega = g**((p - 1) // N) mod p. By construction, (N) divides (p-1), so (omega) has exact order (N) modulo (p).
Compute the number theoretic transform A = [A_0, A_1, ..., A_{N-1}], where for each j = 0, 1, ..., N-1, A_j = sum_{k=0}^{N-1} a_k * omega**(j*k) mod p.
Compute each A_j as its least nonnegative residue in {0, 1, ..., p-1}.
Let ntt_result_1 be this sequence A.
Output the result as task_1_out = {"result": ntt_result_1}, replacing ntt_result_1 with its calculated value.
